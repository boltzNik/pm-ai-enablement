# AI Chatbot For Order Status Questions

## Problem
Customers call support for order status questions, which is expensive and slow.

## Proposal
Deploy a GenAI chatbot using an LLM that identifies the customer by phone number and answers order status questions from order history. We expect the chatbot to deflect 60% of contacts.

## Success Metrics
- Customer happiness: from 4.0 to 4.4 within 12 weeks.

## Guardrail Metrics
- Contact Rate: stop if it rises by more than 1 per 100.
- Delivery CSAT: stop if it falls by more than 0.05.

## Experiment Plan
Randomized by customer. Duration: 3 weeks. MDE: 0.5 contacts per 100, power 80%. Primary metric and stopping rule pre-registered.

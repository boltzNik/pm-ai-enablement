# Weather-Based Promise Windows

## Problem
Storms cause late deliveries because promise windows do not reflect conditions (source: LMD weather impact analysis).

## Proposal
Widen promise windows automatically during severe weather. Follows EXP-014, but only applies during storms rather than permanently.

## Success Metrics
- On-Time Delivery Rate during storms: baseline 78%, target 88% within 8 weeks.

## Guardrail Metrics
- Cost Per Delivery: must not increase.

## Experiment Plan
A/B test randomized by customer. Run for 1 week. Compare on-time rate between arms.

## Reviews And Dependencies
Weather data feed already licensed.
